## Install

```bash
curl -fsSL https://raw.githubusercontent.com/Digital360-Indonesia/inteligence360-cli/main/install.sh | bash
```

Requires **macOS** or **Linux**. Bun will be installed automatically if not found.

---

## First Run

```bash
intelligence360
```

On first launch you'll see:

> `No provider configured · Run /model to pick an AI provider and get started`

Type `/model`, select a provider, paste your API key — it will test the connection and save it. Done.
